# Курс валют и погода в Москве

Самостоятельная страница `index.html`, без зависимостей и API-ключей.

- Валюты: `https://www.cbr-xml-daily.ru/daily_json.js`, поля USD и EUR. Рубли за единицу валюты: `Value / Nominal`. Дата курса показана отдельно и может быть завтрашней.
- Погода: Open-Meteo, координаты Москвы `55.7558, 37.6173`, параметры `temperature_2m` и `precipitation`. Полный URL находится в `WEATHER_URL` в коде страницы.
- Время обновления и дата погоды показаны по Москве. Интервал осадков берётся из ответа API.

При открытии и по кнопке «Обновить» браузер запрашивает оба источника. Есть состояние загрузки, отдельные ошибки для каждого API и тайм-аут 15 секунд. Отказ одного источника не мешает показать данные второго.

Проверка: сравнить валюты с JSON источника; нажать «Обновить»; отключить сеть и повторить; заблокировать один API в инструментах браузера и убедиться, что второй работает.

Сборка общая для сайта, из корня репозитория: `node scripts/build.mjs` с переменной `SITE_URL`.
